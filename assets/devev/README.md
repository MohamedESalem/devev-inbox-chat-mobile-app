# DEVEV Brand Sources

These files are official DEVEV source assets copied from the supplied repository input.

- `logo-source.png`: square DEVEV app/logo source.
- `logo-mark-source.png`: transparent DEVEV mark source used for Android adaptive icon foreground.
- `logo.ico`: supplied favicon source.

The generated app assets referenced by Expo remain at `assets/icon.png`, `assets/adaptive-icon.png`,
`assets/splash.png`, `src/assets/images/logo.png`, and `src/assets/local/logo.png`.

The Android notification small icon generated from the official mark lives in `assets/android-notification-icon/`.
